# Portafolio — Daniela Jacqueline Zúñiga Jiménez

Portafolio profesional de una sola página (ES / EN / FR), autocontenido en `index.html`
(imágenes incrustadas, sin dependencias externas salvo las fuentes de Google Fonts).

## Publicar en GitHub Pages

1. Crea un nuevo repositorio en tu cuenta de GitHub llamado exactamente:
   **`yollotl-mumina.github.io`**
   (debe coincidir con tu usuario de GitHub; así GitHub lo reconoce como sitio personal).
2. Sube el archivo `index.html` de esta carpeta a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Source**, selecciona la rama `main` (o `master`) y la carpeta `/root`.
5. Guarda. En uno o dos minutos el sitio queda publicado en:
   **https://yollotl-mumina.github.io**

## Actualizar el sitio más adelante

Para publicar cambios, sustituye `index.html` por la versión nueva y vuelve a subirlo
(commit + push, o arrastrar el archivo en la interfaz web de GitHub). GitHub Pages
se actualiza solo; si no ves el cambio de inmediato, espera un par de minutos o
fuerza la recarga del navegador (Ctrl/Cmd + Shift + R).

## Nombre de repositorio alternativo

Si prefieres no usar el repositorio de usuario (`yollotl-mumina.github.io`) y en su
lugar quieres un repositorio con otro nombre (por ejemplo `portfolio`), en el paso 4
selecciona la rama `main` igualmente; el sitio quedará publicado en:
**https://yollotl-mumina.github.io/portfolio/**
